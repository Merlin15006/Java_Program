Checking for lesser value using if else if:
 import java.util.*;//for using all func in util use '*'
 public class Main{
    public static void main(String [] args){
        Scanner scan = new Scanner(System.in);
        int a = scan.nextInt();
        int b = scan.nextInt();
        int c = scan.nextInt();
        if(a<b&&a<c){
            System.out.println(a);
        }
        else if(b<c){
            System.out.println(b);
        }
        else{
            System.out.println(c);
        }
    }
}

Powers and rooting
Math.pow -- give 2 values, 1st is the base 2nd is the power, use type casting if needed.... default -> double
Math.sqrt -- one value and returns sqroot.... default -> double
Math.cbrt -- give a value and returns the cube root.... default -> double




rounding
Math.ceil(double) -> rounds and gives the upper value if 5.6 gives 6
Math.floor(double) -> rounds and gives the lower value if 5.6 gives 5
Math.round(float) -> int, Math.round(double) -> long
Math.random() -> double...generates random values
